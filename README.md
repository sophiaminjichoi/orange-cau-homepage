# 오렌지카우 홈페이지

정적 웹페이지입니다. 빌드 단계 없이 그대로 배포할 수 있습니다.

## GitHub에 올리기
1. GitHub에 로그인한 뒤 새 public repository를 만드세요 (예: orange-cau-homepage).
2. 이 폴더 안의 index.html을 저장소 최상위에 업로드하고 커밋하세요.

## Vercel로 배포하기
1. Vercel에 로그인하고 Add New → Project를 선택하세요.
2. GitHub 저장소를 연결하고 Import를 누르세요.
3. Framework Preset은 Other, Build Command는 비움, Output Directory는 기본값 또는 ./ 로 두고 Deploy를 선택하세요.
4. 배포가 완료되면 Vercel이 제공하는 https://...vercel.app 주소로 휴대폰에서 확인하세요.

## 참고
- GitHub/Vercel 계정 로그인과 저장소 연결은 계정 소유자가 직접 해야 합니다.
- 페이지에 표시된 제품 설명은 회사가 공개한 설명이며, 제품별 판매·시식·인허가 상태를 보증하지 않습니다.
